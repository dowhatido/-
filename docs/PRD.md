# 项目产品需求文档 (PRD) v1.1

## 1. 产品概述
* **产品名称**：LensShare 摄影设备租借社区
* **产品定位**：一个集“在线设备租赁”与“摄影内容社区”于一体的垂直共享平台。
* **核心价值**：解决摄影爱好者和初创团队获取高端设备成本高的问题，同时提供一个交流摄影技巧、分享作品的种草社区，实现“社区种草 -> 平台租借 -> 产出分享”的业务闭环。

## 2. 核心功能模块划分
### 2.1 用户认证模块 (Auth)
* **注册/登录**：支持手机号或邮箱注册，支持密码登录。
* **状态管理**：全局维护用户登录态，未登录用户可浏览设备和社区，但下单、评论、访问个人中心需强制登录。

### 2.2 设备租赁模块 (Equipment)
* **设备大厅**：支持按分类（相机、镜头、无人机、配件）筛选设备，展示设备主图、名称、日租金、押金。
* **设备详情**：展示设备详细参数、图文介绍。
* **档期日历**：用户可选择起止日期，系统自动计算总天数和总租金。
* **用户评价**：在设备详情页展示历史租客的真实评价（星级、内容、用户头像）。
* **模拟支付**：生成订单后，提供模拟收银台完成支付流转。

### 2.3 社区互动模块 (Community)
* **瀑布流动态**：展示用户发布的摄影作品、设备评测。
* **互动操作**：支持对动态进行点赞、评论、分享。
* **种草关联**：动态可关联具体拍摄设备，点击标签可直接跳转至设备租赁页。

### 2.4 个人中心模块 (Profile)
* **资料管理**：修改头像、昵称，查看当前信用分。
* **订单管理**：按状态（待支付、待发货、租借中、已完成）分类查看订单。支持“去支付”、“确认归还”、“去评价”等操作。
* **资产与服务**：管理收货地址、我的收藏。
* **在线客服**：提供实时的在线客服聊天窗口，解决售后与咨询问题。
